# README.md  
**Mini NLP Project: Employee Feedback Sentiment, Stress & Topic Analyzer**

## Project Title  
**HR Feedback Analyzer** – Sentiment, Stress/Burnout Detection, Topic Extraction & Actionable HR Recommendations  
(10-sample demo + full reproducible pipeline)

## Overview  
This small project demonstrates a complete end-to-end NLP pipeline for analyzing open-ended employee feedback (pulse surveys, engagement comments, exit interviews, etc.).  
From a single list of 10 realistic feedback messages it automatically extracts:

1. Sentiment (Positive / Negative)  
2. Stress & Burnout level (Low / Medium / High)  
3. Topics & keywords (via BERTopic)  
4. One-sentence extractive summary of the whole set  
5. Actionable HR recommendation tags (e.g., “Wellness Check”, “Career Development”, “Workload Review”)

## Requirements  
Python ≥ 3.8  
Install everything with one command:

```bash
pip install -r requirements.txt
```

**requirements.txt content**

(You may need to install PyTorch with CUDA separately if you have a GPU.)

## How to Scale to Real HR Data  
1. Replace the `feedbacks` list with your actual data (CSV, Excel, database, etc.).
2. (Optional but recommended) Fine-tune a stress model on Dreaddit or your own labeled data – replace the simple keyword rule with a Hugging Face classifier.
3. Switch the summary step to a generative LLM (Grok, Llama-3, GPT-4o, etc.) for natural-language summaries.
4. Deploy as a Streamlit/FastAPI dashboard for HR teams.
